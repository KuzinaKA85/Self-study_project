# SELF-STUDY Project — Платформа для самообучения

SELF-STUDY Project — это платформа для онлайн-обучения, разработанная в рамках дипломного проекта. 
Платформа позволяет студентам изучать материалы, проходить тесты, а преподавателям — 
создавать курсы, разделы, уроки и тесты.

### Технологии

- **Backend:** Python 3.13, Django 6.0, Django REST Framework 3.17
- **База данных:** PostgreSQL
- **Аутентификация:** JWT (djangorestframework-simplejwt)
- **Документация:** drf-yasg (Swagger)
- **Линтеры:** Black, isort, flake8, mypy
- **Тестирование:** coverage 

### Функционал

- **Регистрация и авторизация** с использованием JWT токенов
- **Три роли пользователей:** Администратор, Преподаватель, Студент
- **Управление контентом:** курсы → разделы → уроки → тесты
- **Проверка знаний:** отдельный API-запрос для проверки ответов
- **Админ-панель** для управления всеми сущностями
- **Swagger документация** API
- **Тесты** 
- **CORS** для работы с фронтендом

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/KuzinaKA85/Self-study_project.git
cd self-study-project
```
### 2. Создание виртуального окружения
```bash
python -m venv .venv
source .venv/bin/activate      # macOS/Linux
.venv\Scripts\activate         # Windows
```
### 3. Установка зависимостей 
```bash
pip install -r requirements.txt
```
### 4. Настройка переменных окружения
Создайте файл .env в корне проекта:
```
SECRET_KEY=your-secret-key-here
DEBUG=True   # для разработки
DATABASE_NAME=your_db_name
DATABASE_USER=your_db_user
DATABASE_PASSWORD=your_db_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

### 5. Создание базы данных PostgreSQL
- pgAdmin
```sql
CREATE DATABASE your_db_name;
```
### 6. Создание и применение миграций
```bash
python manage.py makemigrations
python manage.py migrate
```
### 7. Создание суперпользователя
```bash
python manage.py csu
```
### 8. Запуск сервера
```bash
python manage.py runserver
```
Сервер будет доступен по адресу: http://127.0.0.1:8000/

## API Эндпоинты

### 1. Пользователи
| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/users/register/` | Регистрация студента |
| POST | `/users/login/` | Вход (JWT токен) |
| POST | `/users/token/refresh/` | Обновление токена |
| GET/PUT | `/users/profile/` | Профиль текущего пользователя |
| GET/POST/PUT/DELETE | `/users/users/` | Управление пользователями (только админ) |

### 2. Материалы

| Метод | URL | Описание |
|-------|-----|----------|
| GET/POST | `/materials/courses/` | Список/создание курсов |
| GET/PUT/DELETE | `/materials/courses/{id}/` | Детали/обновление/удаление курса |
| GET | `/materials/sections/` | Список разделов (фильтр по курсу) |
| POST | `/materials/sections/create/` | Создание раздела |
| GET/PATCH | `/materials/sections/update/{id}/` | Обновление раздела |
| DELETE | `/materials/sections/delete/{id}/` | Удаление раздела |
| GET | `/materials/lessons/` | Список уроков (фильтр по разделу) |
| POST | `/materials/lessons/create/` | Создание урока |
| GET/PATCH | `/materials/lessons/update/{id}/` | Обновление урока |
| DELETE | `/materials/lessons/delete/{id}/` | Удаление урока |
| POST | `/materials/check-test/` | Проверка ответа на тест |

### 3. Документация

| URL | Описание |
|-----|----------|
| `/swagger/` | Swagger UI (интерактивная документация) |
| `/redoc/` | ReDoc документация |
| `/admin/` | Админ-панель Django |

### 4. Тестирование

- Запуск всех тестов
```bash
coverage run manage.py test
coverage report
```
- Запуск тестов конкретного приложения
```bash
python manage.py test users
python manage.py test materials
```
- Покрытие кода
```bash
coverage html
start htmlcov/index.html   # Windows
open htmlcov/index.html    # macOS
```
### 5. Права доступа

| Роль          | Что может                                                               |
|---------------|-------------------------------------------------------------------------|
| Студент       | Просмотр курсов, уроков, прохождение тестов                             |
| Преподаватель | Создание/редактирование/удаление своих курсов, разделов, уроков, тестов |
| Администратор | Полный доступ ко всем функциям, управление пользователями               |

### 6. CORS
Для работы с отдельным фронтендом настроен CORS:
```
# settings.py
CORS_ALLOW_ALL_ORIGINS = True   # Для разработки
```
